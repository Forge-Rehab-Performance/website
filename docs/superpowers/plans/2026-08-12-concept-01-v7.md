# Concept 01 V7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Compact the Concept 01 FAQ and Pricing pages and replace Services accordions with responsive cards while preserving the V6.1 agency architecture and launch-readiness infrastructure.

**Architecture:** Keep the existing thin routes and shared layouts. Implement presentation changes inside the three section components and scoped V7 rules in the Concept 01 stylesheet. FAQ category switching uses minimal vanilla JavaScript while question disclosure remains native `<details>`.

**Tech Stack:** Astro 7.2.1, TypeScript, static HTML/CSS, minimal browser JavaScript, Node test runner.

## Global Constraints

- Preserve all client-supplied content and pricing.
- Preserve V6.1 BaseLayout/SiteLayout, GA4, canonical, sitemap, robots, and noindex behavior.
- Preserve Concepts 02/03 source exactly.
- Desktop and 390px mobile layouts must avoid horizontal overflow.
- Do not add a UI framework or client island dependency.
