# Forge PT — Concept 01 V7

V7 keeps the V6.1 agency architecture, SEO, analytics, sitemap, and historical-concept preservation while making the three densest information pages substantially more compact and easier to scan.

## Active iteration

- Home: unchanged from V6.1.
- Forge Approach: unchanged from V6.1.
- About: unchanged from V6.1.
- Contact: unchanged from V6.1.
- Services: rebuilt from large accordions into five always-visible responsive service cards. The Orthopedic PT card spans the full desktop grid because it contains the most structured detail; the remaining four services form a two-column desktop grid and one-column mobile flow.
- Pricing: reduced hero height, tighter visit/package cards, condensed guidance/promise treatment, and smaller supporting bands while preserving all supplied rates, savings, package details, Founding Forge 20 copy, and CTAs.
- FAQ: replaced seven stacked page sections with one compact category explorer. Desktop uses a left category rail and right FAQ panel. Mobile uses a horizontally scrollable category tab row above the selected FAQ panel. Questions remain native disclosure controls.
- Concept 02/03: retained for historical comparison, excluded from sitemap, and marked noindex.

## V7 interaction rule

FAQ category switching is the only new custom client-side behavior. It uses framework-free JavaScript and ARIA tab/panel semantics. Question expansion remains native `<details>/<summary>`.

## Review previews

V7 includes desktop and mobile previews for the three changed Concept 01 routes only:

- Services — 1440px desktop and 390px mobile
- Pricing — 1440px desktop and 390px mobile
- FAQ — 1440px desktop and 390px mobile

All prior previews remain in the package for iteration history.

## Remaining clinic placeholders

The supplied clinic material still does not provide the final EMR scheduling URL, phone number, email address, gym name/address, hours, or map details. These remain centralized null/placeholder values rather than fabricated facts.
